## 🔧 Customization Made Easy

### Change Colors
Edit the CSS in any file's `<style>` section:
```css
--primary: #5b3db3;  /* Change this */
```

### Update Content
Just edit the HTML text directly. No build process, no compilation.

### Add New Pages
Copy any existing page → rename → modify content → update navigation links.

### Customize Styling
Use Tailwind classes. Everything is already setup:
```html
<div class="md:grid-cols-2 lg:grid-cols-4 gap-6">
  <!-- Responsive grid -->
</div>
```
